Open index.html in Safari om de site lokaal te bekijken. Laat de map assets naast de HTML-bestanden staan.
Let op: sommige browsers beperken YouTube-embeds wanneer een HTML-bestand rechtstreeks via file:// wordt geopend. De knop “Bekijk op YouTube” blijft dan werken; op een normale https-website werkt de embed zoals bedoeld.
